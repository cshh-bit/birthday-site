# 把《像风一样》放在这里

由于版权原因，网站没有内置薛之谦《像风一样》的音频文件。

请把你已经合法拥有的音频文件命名为：

```
xiang-feng-yi-yang.m4a
```

放在这个文件夹里，然后刷新页面。点击首页的灯球（或右上角 **Tap for sound**），它就会点亮并播放这首歌。

- 支持浏览器能播放的格式；如果文件不是 mp3，请把 `index.html` 里 `<audio id="bgSong">` 的 `src` 改成实际文件名。
- 如果文件不存在，点击灯球会先播放网站自带的音乐盒生日歌，灯球仍然会正常点亮。
- 建议用 128–192kbps 的 mp3，文件不要太大，手机上加载更快。
