# 给王芊予的生日 · 10.28

一个用 HTML / CSS / JavaScript 手写的生日故事网站，没有框架，也没有构建步骤。双击 `index.html` 就能看。

打开后先看到 **生日书封面**：镜面灯球、`Is your birthday!`、10 月 28 日的日期转轮和 `Turn the page`。点 `Turn the page` 进入 **花房**：12 种手绘花，挑 12–15 朵（可重复同一种），组花束，然后直接进入 3 秒倒计时。倒计时结束后放烟花，倒计时结束后放烟花；烟花放完，开场四行文字逐条淡入，再进入后面的六段星空故事。

---

## 打开它

**最简单：** 双击 `index.html`，用浏览器打开。

**本地预览（推荐）：**

```bash
cd birthday-site
python3 -m http.server 8099
```

然后打开 <http://127.0.0.1:8099>。

- 封面点 **Turn the page** 进入花房
- 01 Pick Flowers：挑 12–15 朵，可重复同一种花
- 02 Bouquet：换一种排列，然后直接走进生日书
- 右上角 **skip →** 可以跳过花房
- 封面点击 **Turn the page** 进入花房；花束完成后直接进入故事
- 进入后先看 3 秒倒计时（3 · 2 · 1），结束后星空里会放烟花
- 故事里可以向下滚动，也可以点每一页底部的 **继续**
- 故事页左下角的 **← COVER** 或按 `Esc` 可以回到封面
- 点击灯球（或右上角 **Tap for sound**）会点亮灯球并播放音乐
- 加 `?still=1` 可以跳过花房，并关闭翻页、倒计时、烟花和文案入场动画，方便截图（星空和流星仍会保留）
- 浏览器不允许页面自动出声，所以第一次需要你点一下

## 封面 + 花房（BOUQUET）

生日书封面在前。点 `Turn the page` 进花房，花房只有两步：

1. **Pick Flowers**：12 种花，挑 12–15 朵，可以重复同一种；下方会出现已选花材
2. **生日的一束花**：大花在中间、小花在边缘，换一种排列也不会打乱这个关系，然后直接进入 **生日故事**

12 种花：银莲花、康乃馨、大丽花、雏菊、百合、兰花、芍药、洋牡丹、玫瑰、向日葵、郁金香、百日菊。

花束加了短纸包和丝带，纸包只包住花的下半部分，不遮住花头；背后有浅桃色圆形底。花形和纸包都是 SVG / CSS 画的，不依赖外部图片。花材和颜色在 `assets/js/bouquet.js` 的 `flowers` 数组里，花形在 `index.html` 的 `flower-*` 这组 `<symbol>` 里。

样式在 `assets/css/bouquet.css`，两步流程在 `assets/js/bouquet.js` 里。

## 改成你的版本

### 换名字、年龄和日期

打开 `index.html`，搜索「王芊予」替换即可。年龄 `21` 出现在这些地方：

- 开场：名字、`她 21 岁了`、`21 颗星星`
- 21 颗星星：`已读 0 / 21`、`21 颗星，都送给你`
- 连星爱心：`0 / 21`、`21 颗星，全部属于你`
- 21 岁页：大数字 `21`
- 最后一页：`21岁快乐`

生日日期出现在封面日期转轮、封面 kicker 和信纸上的 `TO 王芊予 · 10.28`。

### 倒计时和烟花

封面翻开后，会先显示 3 秒倒计时（3、2、1），然后开始放烟花。烟花放完后，开场四行文字会逐条淡入：

1. 一个普通的秋天，
2. 有一个女孩来到这个世界。
3. 而今天，她 21 岁了。
4. 所以，我准备了 21 颗星星。

文字全部出现后，底部的 **继续** 才会出现。

- 倒计时在 `assets/js/main.js` 的 `startStoryIntro()`
- 烟花画面是 `#fireworks` canvas，绘制逻辑在 `startFireworks()` / `fireworkBurst()`
- 文字淡入在 `revealIntro()`，四行的延迟在 `index.html` 里的 `--d`
- 倒计时、烟花和文字入场只在第一次翻开故事时播放
- `?still=1` 或系统开启“减少动态效果”时会跳过倒计时和烟花，直接显示文字

### 换 21 颗星星上的话和照片

「21 颗星星」这一页的星星、留言和照片在 `assets/js/main.js` 里：

- `starMessages`：21 段话，点星星时弹出
- `starPhotos`：21 张照片的路径，按 `01.jpg` 到 `21.jpg` 的数字顺序排列
- `starPositions`：21 颗星在页面上的位置，格式是 `[x%, y%]`
- `starField` 会按数组顺序自动生成 21 个按钮

照片放在：

```
assets/photos/star-messages/01.jpg
...
assets/photos/star-messages/21.jpg
```

第一次点击显示 `01.jpg`，第二次显示 `02.jpg`，依次到 `21.jpg`。项目根目录原来的 `1.JPG` 到 `21.JPG`（`13-1.jpg` / `13-2.JPG` 依次对应第 13、14 张）已经按这个顺序压缩后放进去。

星星是 CSS 画的四角闪光，香槟金色、深色描边和柔光，大小错落。颜色和光晕在 `.star-message::before` / `.star-message::after` 里改。

点击后这颗星星会淡出消失，弹窗先出现对应的照片，并保持照片的原始比例。再点击照片（或卡片）会翻转，背面是那一段话；再点一次翻回照片。

底部显示 `已读 n / 21`，21 颗全部点击完后出现「21 颗星，都送给你」。弹窗可以用右上角 ×、背面「关闭」、点背景或 `Esc` 关闭。

### 换连星爱心

爱心由 `assets/js/main.js` 里的 `heartPoints` 控制，共 21 个点：

- 每个点是 `[x, y]`，坐标范围是 600 × 520
- 点完当前闪烁的星，才会亮起下一颗
- 全部点亮后显示 `Happy birthday!` 和名字
- **全部点亮** 会按顺序自动补完

想改完成后的文案，在 `completeHeart()` 里改 `insideHeading` 和 `heartHint`。

### 换颜色

在 `assets/css/style.css` 最上面的 `:root` 里改：

```css
--cream: #f8f1e6;   /* 封面奶油色 */
--wine: #7a2e32;    /* 酒红 */
--rose: #c98988;    /* 玫瑰粉 */
--gold: #b48a4e;    /* 金色 */
```

故事页的深蓝背景在 `.page--inside`，星空和流星在 `.night-sky` / `.star` / `.meteor`，章节样式在 `/* STORY */` 这一段。

### 音乐

点击灯球或右上角声音按钮会播放音乐。由于版权原因，网站没有内置薛之谦《像风一样》的音频。请把你合法拥有的音频命名为：

```
assets/music/xiang-feng-yi-yang.m4a
```

放进去后刷新页面即可。如果文件不存在，会播放网站自带的音乐盒生日歌作为兜底。

- 如果文件不是 mp3，改 `index.html` 里 `<audio id="bgSong">` 的 `src`
- 想只用纯音乐盒生日歌，把 `#bgSong` 的 `src` 留空或删掉
- 音乐盒旋律在 `assets/js/main.js` 的 `const melody = [...]`

## 分享给她

这个网站是纯静态的，把整个 `birthday-site` 文件夹上传到任意静态托管即可：

- **Netlify Drop**：把文件夹拖到 <https://app.netlify.com/drop>
- **Vercel / Cloudflare Pages**：新建项目，上传文件夹，不需要构建命令
- **GitHub Pages**：推到仓库，在 Settings → Pages 里选择分支
- **直接发文件**：压缩整个文件夹发给她，解压后双击 `index.html`

分享卡图在 `assets/og-cover.jpg`。部署后，把 `index.html` 里 `og:image` 和 `twitter:image` 的相对路径改成完整网址，链接预览会更稳定。

## 小细节

- 没有外部字体、CDN、统计脚本；断网也能看
- 手机、平板、桌面自适应；支持 `prefers-reduced-motion`
- 翻页、滚动、信纸、连星都支持键盘操作
- 花房支持键盘选花、换排列和直接进入生日书
- 照片是你们的个人照片，公开部署前想一下访问范围
